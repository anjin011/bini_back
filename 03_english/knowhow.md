# 🔤 영어 선생님 노하우

> 지침(에이전트 파일)은 "무엇을 하는지", 이 파일은 "어떻게 하면 잘 되는지"예요.
> 영어 선생님은 일하기 전에 이 파일을 읽고, 새로 알게 된 점을 아래 4·5번에 쌓아요.

## 1. 공부법 기본기
- **어휘는 매일 조금씩.** 본문 어휘는 뜻 + 동의어·반의어까지 (변형 문제에서 단어가 바뀌어 나온다).
- 긴 문장은 **주어·동사 찾기 → 수식어 괄호 치기**로 구조를 본다.
- 본문은 문단별 요지 한 줄 → 글 전체 주제 한 줄로 요약해 본다.

## 2. 내신 대비 노하우
- 범위 = 교과서 본문 + 부교재 + 모의고사 지문인 경우가 많다. 범위를 먼저 정확히 확인.
- 본문은 **해석 없이 읽어도 내용이 떠오를 정도**로 반복. 핵심 문장은 영작할 수 있게.
- 어법 단골: 관계사(what/that/which), 분사(-ing/-ed), 수 일치, 시제, to부정사·동명사, 가정법, 대명사가 가리키는 것.
- 변형 문제 유형별 요령:
  - **순서·삽입**: 연결어(However, Therefore)와 지시어(this, they, such)가 단서.
  - **주제·제목·요지**: 첫 문단과 마지막 문단, 역접 뒤 문장.
  - **요약문 빈칸**: 본문 핵심어가 동의어로 바뀌어 나온다.
- 서술형 영작은 조건(단어 수, 어형 변화, 주어진 단어 사용)부터 체크.

## 3. 자주 하는 실수
- 해석은 되는데 문장 구조를 몰라서 어법 문제에서 틀림.
- 대명사가 가리키는 대상을 대충 넘김.

- 듣기는 매일 짧게, 빈칸·순서·삽입은 오답률 높은 유형부터.

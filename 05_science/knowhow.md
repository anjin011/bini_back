# 🔬 과학 선생님 노하우

> 지침(에이전트 파일)은 "무엇을 하는지", 이 파일은 "어떻게 하면 잘 되는지"예요.
> 과학 선생님은 일하기 전에 이 파일을 읽고, 새로 알게 된 점을 아래 4·5번에 쌓아요.
> 실제 과목(예: 물리학, 화학, 생명과학, 지구과학 등)이 정해지면 1번을 그 과목에 맞게 다듬어요.

## 1. 공부법 기본기
- 현상을 외우기보다 **"왜 그렇게 되는지"** 원리 한 문장으로 설명할 수 있게.
- 개념은 그림·도식으로 정리하면 오래 간다 (힘의 방향, 반응 과정, 순환 구조 등).
- 공식은 **단위와 함께** 외운다. 단위를 맞춰 보면 계산 실수를 잡을 수 있다.
- 계산 문제는 비슷한 유형을 여러 개 연달아 풀어 손에 익힌다.

## 2. 자료·실험 해석
- 그래프: 가로축·세로축 → 기울기·넓이가 뜻하는 것 → 구간별 변화.
- 실험: **독립 변인(바꾼 것) / 종속 변인(측정한 것) / 통제 변인(같게 한 것)**부터 표시.
- 표 자료는 두 조건을 비교해 "무엇 때문에 달라졌는지"를 찾는다.

## 3. 내신·수행 노하우
- 교과서 탐구 활동과 학교 실험 내용이 출제 단골. 실험 과정·결과·결론을 짧게 정리해 두기.
- 실험 보고서는 가설 → 과정 → 결과(표·그래프) → 결론 → 오차 원인·개선점 순서.
- 수행평가가 끝나면 탐구 내용을 3줄로 `5_research/seteuk-ideas.md`에 남기기 (진로 선생님이 모아요).
